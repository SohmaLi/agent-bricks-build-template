# Widget: `div`

> **Source:** `bricks/includes/elements/div.php` — extends `Element_Container`
> **Category:** layout | **Nestable:** ✅ | **Tag mặc định:** `div`

`div` giống hệt `block` về settings. Xem file [layout-block.md](layout-block.md) để biết đầy đủ.

Khác biệt duy nhất: label hiện trong editor là "**Div**" thay vì "**Block**".

---

## Khi nào dùng `div` thay `block`

- Khi muốn rõ ràng đây là `<div>` thuần HTML
- Wrapper cho các element nhỏ: badge, chip, icon wrapper, meta info
- Semantic rõ hơn trong cấu trúc element tree
